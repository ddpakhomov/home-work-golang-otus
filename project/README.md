# Тренажер технических терминов

## Описание

**Тренажер технических терминов** представляет собой программное обеспечение, предназначенное для помощи пользователям в изучении и повторении основных технических терминов. Программа включает в себя CLI утилиту, которая является основным механизмом для повторения терминов. Программа также предоставляет функциональность для создания, чтения, обновления и удаления (CRUD) терминов через HTTP API, что делает её удобной для интеграции с другими системами и для использования в образовательных целях.

## Основные функции

1. **Создание термина** — позволяет добавлять новые термины и их описания в базу данных.
2. **Чтение терминов** — предоставляет возможность получения списка всех терминов или терминов, относящихся к определенной теме.
3. **Обновление термина** — позволяет обновлять информацию о существующих терминах.
4. **Удаление термина** — удаляет термины из базы данных.
5. **CLI утилита** — основной механизм для повторения терминов, который позволяет пользователям тренироваться в консольном режиме.


### Пример данных

Пример данных, используемых в программе:

```json
[
  {
    "term": "ls",
    "name": "список файлов",
    "description": "Команда для отображения списка файлов и директорий в текущем каталоге.",
    "theme": "linux"
  },
  {
    "term": "pwd",
    "name": "текущая директория",
    "description": "Команда для вывода пути текущей рабочей директории.",
    "theme": "linux"
  }
]
```
