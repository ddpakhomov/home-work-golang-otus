# Tech Term Trainer

Tech Term Trainer — это консольное приложение, предназначенное для помощи пользователям в изучении и практике технических терминов, предоставляя описания и запрашивая у пользователей правильные термины. Приложение извлекает термины из базы данных MongoDB на основе указанной темы.


## Особенности

- Извлечение случайных технических терминов из базы данных MongoDB на основе указанной пользователем темы.
- Предоставление описаний терминов и проверка правильности ввода пользователя.
- Отслеживание и отображение статистики правильных и неправильных ответов.

## Установка

1. Клонируйте репозиторий:

    ```bash
    git clone https://github.com/your-username/tech-term-trainer.git
    cd tech-term-trainer
    ```

2. Установите необходимые зависимости:

    ```bash
    go mod tidy
    ```

## Конфигурация

Создайте файл `config.yml` в корневом каталоге проекта со следующей структурой:

```yaml
mongodb:
  uri: "your-mongodb-uri"
  database: "your-database-name"
  collection: "your-collection-name"
  numDocuments: 5
```

Замените заполнители на ваши фактические URI MongoDB, имя базы данных, имя коллекции и количество документов для выборки.

## Использование

1. Запустите приложение:

    ```bash
    go run main.go
    ```

2. Следуйте инструкциям на экране для ввода темы и начала тренировочной сессии.
